# Грабли и решения

## Windows и консоль

- **Кириллица в выводе Python** падала на cp1252. Решение: `python -I -X utf8`, потому что `PYTHONIOENCODING` вместе с `-I` игнорируется.
- **Open WebUI на кириллице** падал при записи кэша озвучки. Решение: `PYTHONUTF8=1`.
- **PowerShell портил кириллицу**, передаваемую в WSL. В таких командах использовать ASCII.
- **`/tmp` у Git Bash и у Python для Windows — разные папки.** Временные файлы класть в общую папку.
- **CRLF из вывода Python** ломал сравнение хешей в bash.
- **Батники писать с CRLF.** Регулярные выражения в однострочном `powershell -Command` проще писать без обратной косой черты: `ComfyUI.main\.py` вместо `ComfyUI[\\/]main\.py`. Иначе экранирование ломается, и шаблон не ловит путь с `\`.

## Сеть и прокси

- **SSRF-защита Open WebUI** не пускает через прокси на 127.0.0.1 («Blocked non-global address»). Решение: запуск с `NO_PROXY=*`, ходить напрямую.
- **Civitai отвечает 403** на User-Agent `Python-urllib`. Решение: слать UA `curl`.
- **Закрытые репозитории Hugging Face** (Lightricks, BFL) отвечают 403, пока не принята лицензия на странице модели.
- **WSL гасит дистрибутив при простое.** Решение: держать процесс-якорь `wsl --exec sleep infinity`.

## Модели

- **lm-eval с temperature 0 зацикливает Gemma 4.** Нужна официальная выборка.
- **«Расцензуренный» энкодер ломал следование запросу** у LTX-2.5. Решение: официальный int8.
- **NSFW-сборки уводят любые сцены в эротику**, даже нейтральный сюрреализм.
- **Z-Image на короткий запрос рисует самый типичный предмет** («стеклянная рыба» → ваза), а название камеры — саму камеру. FLUX 3 тоже ждёт полное описание; запрос пишет Gemma.
- **Gemma в режиме native через API** иногда отдаёт сырой `<|tool_call>`, хотя в интерфейсе всё работает. Для проверок через API использовать llama.cpp напрямую.
- **Шаблон Gemma 4 закрывает размышления, только если у ассистента непустой `content`.** На этом построен посредник `think_proxy`.
- **Если в системном промпте уже есть `<|think|>`,** шаблон добавляет ещё один. Безвредно.

## Процессы

- **TaskStop не убивает дочерние процессы lm-eval.** Перед перезапуском проверять, что старые процессы мертвы. Иначе два прогона идут одновременно (так и было, результаты оказались годными, но это случайность).
- **Нельзя править скрипт, который сейчас выполняет bash:** bash читает файл по ходу и падает с «unexpected EOF».
- **Перезапускать llama.cpp во время теста нельзя:** тест оборвётся. Изменения `models.ini` применяются только при перезапуске маршрутизатора.
- **Генерация картинки выгружает LLM** (узел `SimpleGenUnloadLLM`), поэтому нельзя одновременно гонять тесты LLM и генерацию.

## Ошибки, которые я сделал и исправил

- **Сбросы NVMe поначалу отнёс к Phison.** На деле это MAXIO: сопоставлять диски надо по AdapterGuid.
- **Скачал Wan Mega v9 вместо v12.2:** смотрел только хвост списка файлов.
- **`stop_all.bat` не ловил пути с обратной косой чертой.** Ошибка экранирования, нашёл при проверке на примерах.
