# ПК и диски

Снимок на 24.10.2026.

## Железо

| Что | Модель |
|---|---|
| Плата | ASRock B650M PG Riptide |
| CPU | AMD Ryzen 7 7700 (8 ядер / 16 потоков) |
| RAM | 2 × 32 GB Kingston KF560C40-32, DDR5-6000. Ещё 2 × 32 GB лежат без дела |
| GPU | NVIDIA RTX 4060 Ti 16 GB (CUDA 13) + встроенная AMD Radeon |
| ОС | Windows 11 Pro 26100 |

**Про вторую пару планок.** Четыре планки DDR5 на AM5 обычно не держат 6000 и падают до 4800–5200. Смысл ставить появится, если понадобится MoE-модель на ~100B параметров (её эксперты живут в обычной памяти). После установки обязателен тест памяти (TestMem5 есть в `D:\shortcuts`).

## Диски

| Буква | Диск | Контроллер | Состояние |
|---|---|---|---|
| C: | Apacer AS2280Q4 1 TB NVMe | Phison E21T | 0 сбросов, 0 ошибок, износ 3% |
| D: | Apacer AS2280Q4 1 TB NVMe | MAXIO MAP1602 | 19 сбросов контроллера и 3 аппаратные ошибки записи за 15 месяцев, износ 1% |
| H: | WD Blue WD10EZEX 1 TB HDD | — | 0 переназначенных секторов |
| — | WD Green 240 GB SATA SSD | — | умер 05.10.2025, BIOS не видит, кабель меняли |

**Подозрение на подделку D: снято.** Почти нулевой серийный номер в Windows — особенность прошивки MAXIO. Через `smartctl` виден настоящий серийник, износ 1%, 14,6 TB записано, ошибок целостности нет. Порог 120 °C — порог предупреждения из прошивки, а не реальная температура.

**Сбои D:.** Разбор журнала `Storport/Operational` (диски сопоставляются по AdapterGuid): запросы зависают примерно на 10 с, после чего контроллер сбрасывается. Последняя аппаратная ошибка записи (22.06.2026 21:48) случилась прямо перед порчей индексов NTFS на D: (21:56). Шум, который надо отсеивать: SenseKey 5 ASC 0x24, Admin Command Error OPC 10, события 557 с нулевой длительностью (сон). Скрипты разбора — `scripts/nvme_export.ps1`, `scripts/nvme_monthly.ps1`.

**Лимит HMB.** Чтобы проверить, не связаны ли сбросы с буфером в памяти ПК (MAXIO — DRAM-less), выставлен лимит HMB 64 MB:

```
HKLM\SYSTEM\CurrentControlSet\Control\StorPort  HmbAllocationPolicy = 2 (DWORD)
```

Действует после перезагрузки. Откат — удалить параметр и перезагрузиться. Через 2–3 месяца сравнить число сбросов. Замер до лимита (winsat, только чтение):

| Диск | Случайное 16K | Последовательное |
|---|---|---|
| C: | 388 / 391 MB/s | 2662 / 2780 MB/s |
| D: | 386 / 480 MB/s | 2086 / 2259 MB/s |

После перезагрузки повторить: `winsat disk -ran -read -drive D` и `winsat disk -seq -read -drive D`.

## Прочее

- `smartmontools` 7.5 поставлен через winget. NVMe видны как `/dev/sdb` (MAXIO) и `/dev/sdc` (Phison) с `-d nvme`.
- Задание `ScheduledDefrag` ни разу не запускалось, поэтому периодический TRIM не идёт. Запустить вручную: `Optimize-Volume -DriveLetter C,D -ReTrim`.
- Интернет идёт через v2rayN (`127.0.0.1:10808`, переменные `HTTP(S)_PROXY`, `ALL_PROXY=socks5h`). В WSL прокси нет.
- Пакеты Python — через `uv` (`uv pip install --python …`, `uv tool install …`).
